# 第4章 硬件系统设计

## 4.1 硬件总体框架与接口定义

### 4.1.1 硬件总体框架

本平台硬件系统以“上层计算平台 + 底层实时控制板”为核心，配合电源管理、电机驱动、传感器和通信接口组成。总体框架如下：

- +-------------------------------------------------------------+
- | 24V锂电池组（2.5Ah）                                        |
- +---------------------------+---------------------------------+
- | 电源管理模块（DC-DC、保护、监测）                            |
- +-------------------+-------------------+---------------------+
- | 24V               | 5V                | 3.3V                |
- +-------v---------+ +--------v-------+ +--------v----------+
- | 关节电机驱动×4  | | 轮毂电机驱动×2 | | 底层MCU板         |
- | (FOC + MOS管)   | | (FOC + MOS管)  | | STM32F405         |
- +-------+---------+ +-------+--------+ +--------+----------+
-          |               |              |
-          | PWM/电流采样   | PWM/电流采样  | SPI/I2C/UART/CAN
-          |               |              |
- +-------v-------------------v-------------------v----------+
- | 传感器模块                                               |
- | IMU（SPI）、编码器（ABZ/SPI）、激光雷达（UART）           |
- | 深度相机（USB3.0）、超声波（GPIO）                        |
- +-----------------------------------------------------------+
-                             |
-                             | CAN 1 Mbps
- +---------------------------v-------------------------------+
- | Wi-Fi                                                     |
- +-----------------------------------------------------------+

### 4.1.2 接口定义

| 接口 | 连接对象 | 信号类型 | 说明 |
| :--- | :--- | :--- | :--- |
| CAN1 | 上层计算平台 | CAN_H, CAN_L | 1 Mbps，扩展帧，终端电阻120Ω |
| SPI1 | IMU | SCLK, MOSI, MISO, CS, INT | 10 MHz，模式0 |
| I2C1 | 磁编码器×4 | SDA, SCL | 400 kHz，地址0x40~0x4F |
| UART2 | 激光雷达 | TX, RX, 3.3V TTL | 115200 bps |

所有外部接口均采用防静电保护（TVS管）和限流电阻，连接器选用带锁扣的型号，防止振动松脱。

## 4.3 电源系统与电池管理

### 4.3.1 电源树设计

电源输入为24V锂电池组，经多级DC-DC转换为各模块所需电压：

### 24V电池输入 ──┬── 24V直接供电：关节电机驱动、轮毂电机驱动
### ├── DC-DC降压 12V/3A：激光雷达（如需要）、风扇
### ├── DC-DC降压 5V/5A：上层计算平台、USB设备、编码器
### └── DC-DC降压 3.3V/1A：底层MCU、逻辑电路、传感器

选用同步降压转换器提高效率：

| 输出 | 芯片型号 | 输入范围 | 输出电流 | 效率 |
| :--- | :--- | :--- | :--- | :--- |
| 12V | TPS5430 | 5.5~36V | 3A | >90% |
| 5V | MP1584 | 4.5~28V | 3A | >90% |
| 3.3V | AMS1117-3.3 | 4.75~12V | 1A | 线性 |

电机驱动部分直接使用24V，避免中间转换损耗。关节电机驱动电路板上集成驱动芯片和MOS管，直接由24V供电。

### 4.3.2 电池选型与充放电管理

**电池选型**：选用6节18650锂离子电芯组成的电池组，标称电压22.2V（6S），满充电压25.2V，容量2.5Ah，持续放电能力≥10A，峰值放电能力≥20A。电池组内集成保护板（BMS），具备过充、过放、过流、短路保护。

**充放电管理**：

- 充电采用外置充电器，输出25.2V/2A，通过DC插座连接电池组充电端口。
- 电池组输出端串联自恢复保险丝（PPTC，5A），防止持续过流。
- 放电回路串联MOS管开关，由底层MCU控制通断，实现软启动和紧急断电。

### 4.3.3 电压电流监测与保护电路

**电压监测**：使用电阻分压将24V分压至3.3V范围内，接入MCU ADC通道。分压比1:10（上臂100kΩ，下臂10kΩ），24V对应2.4V。

**电流监测**：在电池输出端串联0.005Ω采样电阻（精密锰铜丝电阻），使用INA226电流/功率监测芯片，通过I2C接口读取电流和电压。INA226量程±36V/±10A，分辨率16位，满足监测需求。

**保护电路**：

- **过流保护**：当检测电流超过设定阈值（如15A持续100ms），MCU立即切断电机驱动使能，并发送故障码。
- **欠压保护**：电池电压低于18V时，触发报警并降低电机输出；低于16.5V时强制断电。
- **防反接保护**：电池输入串联肖特基二极管或使用理想二极管控制器。
- **急停**：外置急停开关，按下后直接切断电机驱动电源，同时通知MCU。

## 4.4 电机驱动与执行器电路

### 4.4.1 轮式驱动电路设计

轮毂电机为三相无刷电机，采用**FOC（磁场定向控制）**驱动方式。驱动电路由MCU输出6路PWM，经栅极驱动器驱动6个MOS管组成三相全桥。

**MOS管选型**：选用N沟道MOS管，耐压≥40V，连续电流≥10A，低导通电阻（<10mΩ）。推荐型号：AON6994（双N沟道，30V，20A，4.2mΩ）。

**栅极驱动器**：选用IR2104S（半桥驱动器），自举电容供电，支持高边驱动。每相一个IR2104S，共3个。

**电流检测**：在两相桥臂下端串联0.005Ω采样电阻，经运算放大器放大后接MCU ADC。

**关键电路描述**（以U相为例）：

- MCU PWMU_H接IR2104S的HIN，PWMU_L接LIN。
- IR2104S的HO接上桥MOS管栅极，LO接下桥MOS管栅极。
- 自举电容（1uF/50V）接在VB和VS之间。
- 下桥MOS管源极串联采样电阻至地，采样电阻两端经运放放大（增益20）后接ADC。

### 4.4.2 腿部关节驱动电路设计

腿部关节电机功率较大，同样采用FOC驱动，但MOS管规格提高：

- 髋关节：MOS管耐压≥40V，连续电流≥20A，峰值≥40A。
- 膝关节：MOS管耐压≥40V，连续电流≥15A，峰值≥30A。

选用分立MOS管或集成驱动模块。为简化设计，可选用**集成FOC驱动芯片**，如DRV8301（三相栅极驱动器+电流检测放大器），配合外部MOS管实现。

DRV8301特性：

- 支持6~60V输入，适合24V系统。
- 集成3个半桥栅极驱动器，可驱动高/低边MOS管。
- 集成双电流检测放大器，可配置增益。
- SPI接口配置参数。

每路关节驱动板包含：DRV8301 + 6个MOS管（如CSD18540Q5B，40V，50A）+ 电流采样电阻 + 保护电路。MCU通过PWM控制DRV8301，通过SPI读取状态。

### 4.4.3 驱动隔离与保护电路

**隔离**：MCU与功率级之间使用数字隔离器（如ISO7240）隔离PWM信号，或使用光耦（如HCPL-2630）隔离。本平台采用磁隔离芯片（ADuM1400）隔离SPI和PWM，防止功率级噪声干扰MCU。

**保护电路**：

- **过流保护**：硬件比较器监测采样电阻电压，超过阈值时触发DRV8301的FAULT引脚，硬件封锁PWM。
- **过温保护**：MOS管散热片上贴NTC热敏电阻，MCU采集温度，超过80℃时降功率或停机。
- **欠压锁定**：DRV8301内置欠压锁定，电压低于阈值时自动关闭驱动。

## 4.5 传感器选型与接口电路

### 4.5.1 激光雷达与深度相机

**激光雷达**：选用单线激光雷达（如RPLIDAR A1或YDlidar X4），测量半径≥12 m，扫描频率5~10 Hz，角度分辨率1°。接口为UART TTL，通过USB转UART或直接接MCU UART。本平台将激光雷达直接连接到上层计算平台的USB口（通过USB转UART芯片CP2102），上层驱动读取点云数据。

**深度相机**：选用Intel RealSense D435i，具备深度图像和RGB图像，内置IMU（加速度计+陀螺仪），通过USB3.0连接上层计算平台。D435i近距工作距离0.15 m，深度分辨率1280×720@30fps，满足避障和视觉检测需求。

### 4.5.2 IMU与编码器

**IMU**：选用MPU6050或ICM-20948。ICM-20948集成9轴（加速度计、陀螺仪、磁力计），通过SPI或I2C接口连接底层MCU。本平台使用SPI接口，速率10 MHz。IMU安装在身体质心附近，减少线加速度影响。量程：陀螺仪±2000 dps，加速度计±16 g。底层MCU以1 kHz频率读取IMU数据，用于姿态估计。

**编码器**：

- **关节编码器**：每个关节电机输出端安装4096线磁编码器（如AS5047P），通过SPI或PWM输出角度。本平台使用SPI接口连接MCU，分辨率14位（16384脉冲/圈），绝对位置输出。
- **轮端编码器**：轮毂电机内置霍尔编码器，输出A/B/Z三相差分信号，通过编码器接口连接MCU定时器编码器模式。分辨率4096线（AB相倍频后16384计数/圈）。

### 4.5.3 超声波/红外等辅助传感器

**超声波传感器**：选用HC-SR04或兼容型号，量程2~400 cm，精度±1 cm，用于近程避障冗余。两个超声波模块安装在身体前方和后方，通过MCU GPIO控制TRIG和读取ECHO脉冲宽度。

**红外传感器**：可选装红外避障模块（如GP2Y0A21），模拟量输出，用于低空障碍物检测。本平台暂不配备，保留接口。

## 4.6 CAN/RS485等通信总线设计

### 4.6.1 CAN总线设计

**收发器**：选用TJA1050（高速CAN收发器），支持1 Mbps速率，差分信号。

**电路设计**：

- MCU CAN_TX接TJA1050 TXD，CAN_RX接RXD。
- TJA1050的CANH和CANL之间接120Ω终端电阻（总线两端各一个）。
- 在CANH和CANL对地各接一个TVS管（如PESD1CAN），保护收发器免受浪涌。
- 在TXD和RXD上串联22Ω电阻，减少反射。

**连接器**：使用4针连接器（CANH, CANL, GND, 屏蔽层），采用双绞线连接。

### 4.6.2 RS485总线（预留）

为扩展外部设备（如环境传感器、报警灯），预留一路RS485总线。选用SP3485收发器，半双工，MCU通过UART+方向控制引脚驱动。RS485总线加120Ω终端电阻和TVS保护。

## 4.7 原理图与PCB设计要点

### 4.7.1 原理图设计

- 电源部分：多路DC-DC，输入输出加去耦电容（10uF+0.1uF并联），大电流路径加粗。
- 电机驱动：PWM信号加RC滤波，减少振铃；栅极串联10~22Ω电阻；自举电容靠近驱动器放置。
- 传感器接口：IMU芯片电源加LC滤波，减少噪声；SPI信号加串联电阻匹配。
- 保护电路：急停开关直接切断电机电源，同时通过光耦隔离通知MCU。

### 4.7.2 PCB布局布线

- **电源层与地层**：4层板设计，内层为GND和VCC，提供低阻抗回路。
- **功率区与信号区分离**：MOS管、驱动器和采样电阻布置在板子一侧，MCU和传感器接口布置在另一侧，中间用地线隔离。
- **散热**：MOS管底部焊盘大面积铺铜，并加过孔到内层地，必要时加散热片。
- **走线宽度**：24V主电流路径走线宽度≥3 mm（铜厚1 oz），采样电阻走线尽量短且采用开尔文接法。
- **EMC**：CAN总线差分走线等长、等间距；PWM信号尽量短；电源输入加共模扼流圈和X/Y电容。
- **连接器**：所有对外连接器加ESD保护器件（TVS、ESD二极管）。

### 4.7.3 关键器件封装

| 器件 | 封装 | 散热焊盘 |
| :--- | :--- | :--- |
| MOS管 | DFN5×6 | 有，需焊接到大面积铜 |
| 栅极驱动器 | SOIC-8 | 无 |
| MCU | LQFP-64 | 无 |
| DC-DC | SOIC-8 | 有 |
| CAN收发器 | SOIC-8 | 无 |

## 4.8 硬件调试与故障排查

### 4.8.1 调试流程

1. **电源测试**：焊接完成后，先不上主控，单独测试各路DC-DC输出电压是否正常。
2. **MCU最小系统**：焊接MCU及晶振、复位电路，烧录测试程序，点亮LED，确认MCU工作。
3. **CAN通信**：连接USB-CAN工具，MCU发送测试帧，确认CAN收发正常。
4. **电机驱动**：逐个测试电机，先开环给PWM，观察电机是否转动；再闭环测试电流环和速度环。
5. **传感器**：读取IMU、编码器、超声波数据，验证数据正确性。
6. **整机联调**：连接上层计算平台，运行ROS节点，验证完整数据流。

### 4.8.2 常见故障与排查

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 电源无输出 | DC-DC虚焊、芯片损坏 | 检查焊接，用万用表测量输入输出 |
| MCU不工作 | 晶振不起振、复位异常 | 示波器看晶振波形，检查复位电路 |
| CAN通信失败 | 终端电阻未接、波特率不一致、收发器损坏 | 检查电阻，用示波器看CAN波形 |
| 电机不转 | PWM无输出、MOS管损坏、驱动使能未打开 | 检查PWM波形，测量MOS管栅极电压 |
| 电机电流过大 | 参数配置错误、负载过大 | 检查FOC参数，减小负载 |
| IMU数据漂移 | 供电噪声大、未标定 | 加滤波，执行标定 |
| 编码器角度跳变 | 接线接触不良、磁编码器间隙大 | 检查连接，调整间隙 |

## 4.9 实战：从原理图到实机硬件点亮

### 4.9.1 任务目标

完成底层驱动板焊接与调试，实现以下功能：

- DC-DC各电压输出正常。
- MCU烧录程序，LED闪烁。
- CAN通信正常，PC能收发数据。
- 轮毂电机低速转动。
- 关节电机位置闭环运动。

### 4.9.2 步骤

**步骤1：焊接与初步检查**

按原理图焊接元器件，先焊电源部分，再焊MCU和驱动部分。焊接完成后用万用表测量各电源对地阻抗，确认无短路。

**步骤2：上电测试电源**

只连接电池，不插MCU和其他模块。测量12V、5V、3.3V输出是否正常，纹波是否在允许范围内（<50mV）。

**步骤3：烧录MCU测试程序**

编写一个简单的LED闪烁程序，通过ST-Link烧录到STM32F405。上电后观察LED是否正常闪烁。

**步骤4：CAN通信测试**

编写CAN发送程序，MCU每秒发送一帧测试数据。连接USB-CAN工具到PC，使用CAN分析软件查看是否收到数据。再编写CAN接收程序，从PC发送指令，MCU收到后改变LED状态。

示例CAN初始化代码已在第2章给出，此处补充LED控制代码：

```c
// 在main循环中，根据CAN指令控制LED
if (received_cmd == 0x01) {
    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
} else if (received_cmd == 0x00) {
    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
}
```

**步骤5：轮毂电机开环转动**

配置TIM2输出PWM，频率20 kHz，占空比从10%逐渐增加，观察电机是否转动。确认电机转向正确后，增加电流采样，实现简单的速度闭环（使用编码器反馈）。

```c
// 轮毂电机PWM输出初始化
TIM_HandleTypeDef htim2;
htim2.Instance = TIM2;
htim2.Init.Prescaler = 0;
htim2.Init.CounterMode = TIM_COUNTERMODE_UP;
htim2.Init.Period = 8399;  // 168MHz/8400 = 20kHz
htim2.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
HAL_TIM_PWM_Init(&htim2);

TIM_OC_InitTypeDef sConfigOC;
sConfigOC.OCMode = TIM_OCMODE_PWM1;
sConfigOC.Pulse = 4200;  // 50%占空比
sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
sConfigOC.OCFastMode = TIM_OCFAST_DISABLE;
HAL_TIM_PWM_ConfigChannel(&htim2, &sConfigOC, TIM_CHANNEL_1);
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
```

**步骤6：关节电机位置闭环**

配置TIM1输出互补PWM，驱动关节电机。读取磁编码器角度，实现位置环。目标角度设为0°，观察电机是否稳定在目标位置。

```c
// 位置环控制（简化，周期1ms）
float kp = 0.5;
float target_angle = 0.0f;
float current_angle = read_encoder();
float error = target_angle - current_angle;
float output = kp * error;

// 限制输出
if (output > 1.0f) output = 1.0f;
if (output < -1.0f) output = -1.0f;

set_motor_torque(output);
```

**步骤7：整机硬件点亮**

将所有模块连接，包括电池、底层驱动板、上层计算平台、激光雷达、相机。上电后，观察各模块指示灯状态。通过上层ROS节点发送cmd_vel指令，验证机器人能响应。记录测试结果，撰写测试报告。

### 4.9.3 安全注意事项

- 调试电机时，将机器人悬空或置于安全支架，防止意外移动。

- 大电流测试时，注意MOS管温度，避免过热损坏。

- 使用ST-Link调试时，确保供电正常，避免反插。

- 在连接或断开电池时，务必先断开负载。

完成本章实战后，读者应掌握轮腿式机器人硬件系统的设计、焊接、调试和故障排查方法，具备独立搭建硬件平台的能力。
