# 第3章 机械结构设计

## 3.1 轮腿复合机构总体方案选型

轮腿复合机器人按腿部数量和轮腿耦合方式可分为多种方案。针对安保巡逻场景，主要候选方案包括四足轮腿式、双足轮腿式和轮腿分离式。各方案对比如下：

| 方案 | 越障能力 | 移动效率 | 结构复杂度 | 体积质量 | 适用场景 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 四足轮腿式 | 强 | 中 | 高 | 大、重 | 复杂野外地形 |
| 双足轮腿式 | 中 | 高 | 中 | 小、轻 | 半结构化园区、楼宇 |
| 轮腿分离式 | 弱 | 高 | 低 | 中 | 平坦室内 |

本平台选择**双足轮腿式**方案，理由如下：

1. **通过性与机动性平衡**：双足轮腿机器人依靠髋、膝二自由度实现身体高度调节和越障，轮式模式保留高效率移动能力。
2. **结构紧凑**：双足构型体积小、重量轻，可通过窄门、进入电梯，适合楼宇与园区过渡巡逻。
3. **控制可行性**：矢状面内的倒立摆平衡问题已有成熟控制方法，工程实现风险可控。

总体结构由身体、两条对称腿部、两个驱动轮组成。每条腿包含髋俯仰和膝俯仰两个旋转关节，末端安装轮毂电机一体轮。身体承载电池、上层计算平台、传感器支架和底层控制器。

## 3.2 腿部结构设计

### 3.2.1 关节自由度分配

每条腿配置两个主动旋转自由度，均位于矢状面内：

| 关节 | 自由度方向 | 运动范围 | 功能 |
| :--- | :--- | :--- | :--- |
| 髋关节 | 俯仰（绕横滚轴） | -60° ~ +60° | 调节身体高度、前后倾斜 |
| 膝关节 | 俯仰（绕横滚轴） | -130° ~ 0° | 小腿摆动、越障、下蹲 |

轮子绕其自身轴旋转，提供连续滚动驱动，作为第三条运动链。整机共4个腿关节电机和2个轮毂电机，合计6个执行器。两轮差速实现转向，无需额外转向机构。

该自由度分配满足以下要求：
- 矢状面内动力学完全可控，实现站立平衡和动态行走/跳跃。
- 关节数量最小化，降低质量与成本。
- 双腿对称布置，便于控制解耦和模块化维护。

### 3.2.2 腿节结构与关节驱动单元

**腿节尺寸**：大腿长度220 mm，小腿长度220 mm，站立时髋轴距地面约440 mm，身体底部距地面约350 mm。腿节采用碳纤维管制作，外径20 mm、内径16 mm，质量轻且抗弯刚度高。碳纤维管两端通过铝合金接头与关节模块连接。

**关节驱动单元**：每个关节由无刷电机、行星减速器和输出编码器组成。驱动单元参数如下：

| 参数 | 髋关节 | 膝关节 |
| :--- | :--- | :--- |
| 电机类型 | 无刷直流电机 | 无刷直流电机 |
| 额定电压 | 24 V | 24 V |
| 减速比 | 6:1 | 6:1 |
| 峰值输出力矩 | ≥12 N·m | ≥8 N·m |
| 额定输出力矩 | 6 N·m | 4 N·m |
| 输出端编码器 | 4096线磁编码器 | 4096线磁编码器 |
| 质量 | 约350 g | 约280 g |

髋关节驱动单元安装于身体侧板，输出轴与大腿上端固定。膝关节驱动单元安装于大腿下端，输出轴与小腿上端固定。电机与减速器一体化设计，输出轴与关节旋转轴同轴，避免同步带传动带来的间隙和柔性。

**关键设计要点**：
- 驱动单元尽量靠近身体质心，减小腿部转动惯量。
- 关节轴线严格平行，保证双腿运动平面一致。
- 电机线缆从腿杆中空穿过，避免运动干涉。

### 3.2.3 足端/轮端接口设计

小腿末端设计U型铝合金叉架，轮毂电机的定子轴通过两个法兰轴承安装于叉架两侧。轮毂电机转子与轮胎一体，绕定子轴旋转。接口结构如下：

- **轮轴**：定子轴直径12 mm，材料40Cr，表面镀硬铬。
- **叉架**：7075铝合金CNC加工，壁厚3 mm，开口宽度35 mm。
- **轴承**：两侧各一个深沟球轴承（内径12 mm，外径28 mm）。
- **轮胎**：实心橡胶轮胎，直径100 mm，宽度28 mm，邵氏硬度65A。

轮毂电机电源线和编码器线从定子轴中心孔引出，沿小腿管内部上行至身体，避免外露线缆缠绕。

## 3.3 轮式驱动与悬挂设计

### 3.3.1 轮式驱动单元选型

选用轮毂电机作为轮端驱动，参数如下：

| 参数 | 数值 |
| :--- | :--- |
| 额定电压 | 24 V |
| 额定功率 | 60 W |
| 额定转速 | 300 rpm |
| 峰值扭矩 | 2.5 N·m |
| 连续扭矩 | 1.2 N·m |
| 编码器 | 4096线霍尔编码器 |
| 质量（含轮胎） | 约450 g |

轮毂电机集成度高，省去减速器和传动轴，有效降低末端质量。两轮独立驱动，通过差速实现转向。最高轮速对应移动速度约2.5 m/s（轮径100 mm，转速约477 rpm时达2.5 m/s，考虑电机峰值转速，设计足够裕量）。

### 3.3.2 悬挂与减震机构设计

本平台采用**被动减震与主动控制结合**的方案，不设传统弹簧-阻尼悬挂系统。

**被动减震**：在轮毂电机定子轴与小腿叉架连接处安装4个橡胶减震衬套（外径16 mm，内径12 mm，厚度5 mm），吸收地面高频振动和微小冲击，保护电机和结构件。

**主动减震**：腿部关节控制器运行阻抗控制，在轮式模式下根据IMU检测到的垂直加速度实时调整髋、膝力矩，等效于可变刚度悬挂。该方式响应快、适应性强，可有效过滤中等强度地面激励。

采用该方案的原因：传统悬挂会增加末端质量，且轮腿机器人的腿部本身具备主动调节能力，无需额外机械结构。

### 3.3.3 轮腿复合接口与切换机构

轮腿复合的“切换”本质上是控制模式切换，机械结构上无分离动作。轮子始终连接在小腿末端，两种模式通过以下方式实现：

- **轮式模式**：轮毂电机驱动，髋、膝关节采用位置保持或阻抗控制，维持身体高度和姿态。轮子作为唯一接地端。
- **腿式模式**：轮毂电机抱闸锁死，轮子作为固定支撑点。髋、膝关节执行步态轨迹，实现越障、爬坡或台阶攀爬。

为实现轮子锁死，轮毂电机集成电磁制动器（断电抱闸，通电释放），在腿式模式下对电机施加制动信号。制动器静态制动力矩≥1.5 N·m，足以防止轮子滚动。

## 3.4 关键零部件材料与强度校核

### 3.4.1 静力学分析

**材料选择**：

| 部件 | 材料 | 屈服强度 | 密度 |
| :--- | :--- | :--- | :--- |
| 身体板 | 碳纤维板（3K斜纹，2 mm） | — | 1.6 g/cm³ |
| 腿杆 | 碳纤维管（20×16 mm） | 抗弯强度约800 MPa | 1.6 g/cm³ |
| 关节支架/叉架 | 7075-T6铝合金 | 505 MPa | 2.81 g/cm³ |
| 紧固件 | 12.9级合金钢螺栓 | 1080 MPa | 7.85 g/cm³ |

**载荷工况**：以整机质量5 kg计算，重力约50 N。考虑2倍动载系数，设计载荷取100 N。最危险工况为单腿支撑（跳跃落地瞬间），此时单侧腿承受全部载荷，并在髋关节处产生最大弯矩。

**大腿弯曲校核**（碳纤维管外径20 mm，内径16 mm）：

截面惯性矩：

\[
I = \frac{\pi (D^4 - d^4)}{64} = \frac{\pi (20^4 - 16^4)}{64} \approx 5270 \text{ mm}^4
\]

最大弯矩（取腿长220 mm，力臂约0.2 m，载荷100 N）：

\[
M = F \times L = 100 \times 0.2 = 20 \text{ N·m}
\]

最大弯曲应力：

\[
\sigma = \frac{M \cdot y_{\max}}{I} = \frac{20 \times 10^3 \times 10}{5270} \approx 38 \text{ MPa}
\]

碳纤维管抗弯强度约800 MPa，安全系数远大于2，满足要求。

**髋关节支架校核**（铝合金7075-T6，最小截面积约40 mm²，受剪切）：最大剪力100 N，剪应力约2.5 MPa，远低于许用剪应力（约300 MPa），安全。

### 3.4.2 疲劳与冲击校核

跳跃落地或台阶冲击时，动载系数可达3~5倍自重，即瞬时载荷最大250 N。对关键紧固件和关节轴进行疲劳分析：

- **螺栓**：选用M3~M4 12.9级螺栓，预紧力约3~5 kN，剪切面承受动态载荷，安全裕度充足。
- **关节轴**：直径10 mm，40Cr材料，表面硬化处理。按交变弯曲应力校核，疲劳极限约400 MPa，实际最大应力不足50 MPa，疲劳寿命满足要求。
- **碳纤维管**：碳纤维复合材料抗疲劳性能良好，但需注意接头处胶接/螺栓连接产生的应力集中。采用金属接头包裹碳管，避免直接钻孔。

建议对整机进行模态分析，确保最低阶固有频率高于10 Hz，避开控制带宽和地面激励频率。

## 3.5 结构装配流程与维护要点

### 3.5.1 装配流程

1. **腿部组件装配**：将髋关节驱动单元与大腿上端接头连接，膝关节驱动单元与大腿下端接头连接，小腿上端与膝关节输出端连接。
2. **轮端安装**：将轮毂电机定子轴装入小腿末端叉架，安装轴承和橡胶衬套，锁紧螺母。
3. **身体装配**：将两条腿的髋关节驱动单元安装到身体左右侧板，连接碳纤维板，固定电池仓和传感器支架。
4. **线缆敷设**：所有电机和编码器线缆从小腿、大腿中空管穿过，汇总至身体内部，连接底层驱动板。
5. **传感器安装**：安装IMU（身体质心附近）、激光雷达支架、深度相机支架。
6. **整体检查**：检查关节转动灵活性、线缆无干涉、螺栓扭矩、编码器零点。

### 3.5.2 维护要点

| 项目 | 周期 | 方法 |
| :--- | :--- | :--- |
| 螺栓扭矩 | 每月 | 使用扭矩扳手按额定值复紧 |
| 轮胎磨损 | 每季度 | 检查胎面磨损，必要时更换 |
| 关节轴承润滑 | 每半年 | 补充润滑脂，检查游隙 |
| 线缆检查 | 每月 | 检查绝缘层、接头松动 |
| 编码器零点 | 每次上电 | 执行自检，必要时重新标定 |

## 3.6 实战：关键结构件设计检查与装配验证

### 3.6.1 任务目标

完成腿部结构装配，检查关键尺寸、关节灵活性和线缆走线，验证装配质量。

### 3.6.2 检查清单

| 序号 | 检查项目 | 标准 | 工具 |
| :--- | :--- | :--- | :--- |
| 1 | 髋、膝关节轴线平行度 | 偏差≤0.1 mm | 游标卡尺、平台 |
| 2 | 关节转动灵活性 | 无卡滞，空载力矩≤0.1 N·m | 力矩扳手 |
| 3 | 轮子端面跳动 | ≤0.3 mm | 百分表 |
| 4 | 线缆走线 | 无外露、无干涉、无张力 | 目视 |
| 5 | 螺栓扭矩 | 符合规定值 | 扭矩扳手 |
| 6 | 编码器输出 | 旋转关节，角度变化正确 | 上位机 |

### 3.6.3 验证方法

1. **手动转动关节**：缓慢转动髋、膝关节，感受阻力均匀性，观察编码器角度变化是否连续。
2. **轮子空转测试**：对轮毂电机通电，给定低速指令，观察轮子旋转平稳，无异常噪声。
3. **整体晃动测试**：固定身体，轻轻晃动腿部，检查各连接处有无松动或异响。
4. **负载测试**：双手按压身体，模拟动态载荷，观察结构变形和关节响应。

### 3.6.4 常见问题与排查

| 问题 | 可能原因 | 解决方法 |
| :--- | :--- | :--- |
| 关节转动卡滞 | 轴承安装不正、减速器缺油 | 重新装配，补充润滑脂 |
| 轮子端面跳动大 | 轮胎安装不同心 | 重新安装轮胎，调整锁紧螺母 |
| 编码器角度跳变 | 磁编码器与磁铁间隙过大 | 调整间隙至0.5~1 mm |
| 线缆摩擦 | 走线孔边缘锋利 | 加装护线套，打磨孔口 |

完成本章实战后，读者应掌握双足轮腿机器人腿部结构的装配与检查方法，为后续硬件调试和控制实验奠定基础。
