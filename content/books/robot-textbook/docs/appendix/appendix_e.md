## 附录E 常见故障排查表

### E.1 机械系统

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 关节转动卡滞 | 轴承安装不正、减速器缺油 | 重新装配，补充润滑脂 |
| 关节异响 | 螺栓松动、轴承磨损 | 检查扭矩，更换轴承 |
| 轮子端面跳动大 | 轮胎安装不同心 | 重新安装轮胎，调整锁紧螺母 |
| 机器人跑偏 | 轮径不一致、轮距参数错误 | 校准轮径，修正轮距 |
| 结构变形 | 动态载荷过大、材料疲劳 | 有限元复核，更换加强件 |

### E.2 硬件系统

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 电源无输出 | DC-DC虚焊、芯片损坏 | 检查焊接，测量输入输出 |
| MCU不工作 | 晶振不起振、复位异常 | 示波器看晶振波形，检查复位电路 |
| 电机不转 | PWM无输出、MOS管损坏、驱动使能未打开 | 检查PWM波形，测量MOS管栅极电压 |
| 电机电流过大 | 参数配置错误、负载过大 | 检查FOC参数，减小负载 |
| 电源纹波过大 | 滤波电容不足、地线布局差 | 增加去耦电容，优化PCB布局 |

### E.3 软件系统

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| IMU数据为零 | SPI通信失败、CS引脚错误 | 逻辑分析仪抓取SPI波形 |
| 编码器角度跳变 | 接触不良、磁场干扰 | 检查连接，调整磁铁与芯片间距 |
| 看门狗复位 | 控制中断超时、死循环 | 检查中断执行时间，优化代码 |
| 导航定位丢失 | 激光雷达被遮挡、AMCL粒子发散 | 清洁雷达，重新设置初始位姿 |
| 任务无法启动 | 任务配置文件格式错误 | 检查JSON/YAML语法 |
| 报警不触发 | 感知节点未发布事件 | 检查感知系统话题 |

### E.4 运动控制

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 机器人无法站立 | 平衡控制器参数不正确、IMU零偏未校准 | 重新标定IMU，调整LQR增益 |
| 轮式移动抖动 | 速度环增益过大、编码器噪声 | 降低速度环Kp，滤波编码器 |
| 转向过度/不足 | 差速解算错误、轮径不一致 | 校准轮径，修正轮距参数 |
| 越障时摔倒 | 步态轨迹不合理、重心超出支撑域 | 调整步态参数，降低抬腿高度 |
| 模式切换摔倒 | 切换条件不满足、执行过快 | 降低切换速度，增加过渡 |

### E.5 感知与导航

| 故障现象 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 夜间图像噪声大 | 相机增益过高 | 调整曝光参数，增加补光 |
| 激光雷达受干扰 | 强光或反射面 | 调整安装角度，滤除异常点 |
| 目标检测漏检 | 模型训练不足、光照变化 | 收集夜间数据微调模型 |
| 时间同步误差 | 节点负载过高 | 降低分辨率，优化回调 |
| 超声波误报 | 声波反射、串扰 | 调整安装位置，增加滤波 |
