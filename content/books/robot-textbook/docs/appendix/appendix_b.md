## 附录B 核心接口定义与通信协议

### B.1 CAN总线协议

**物理层**：CAN 2.0B，标准帧（11位ID），速率1 Mbps，终端电阻120 Ω。

**帧ID分配**：

| 帧ID | 方向 | 名称 | 数据长度 |
| :--- | :--- | :--- | :--- |
| 0x100 | 底层→上层 | 状态帧 | 8字节 |
| 0x200 | 上层→底层 | 速度指令帧 | 8字节 |
| 0x300 | 上层→底层 | 参数配置帧 | 8字节 |
| 0x400 | 双向 | 心跳帧 | 8字节 |

**数据编码缩放因子**：

| 数据 | 缩放因子 | 单位 |
| :--- | :--- | :--- |
| 姿态角 | 1000 | rad |
| 关节角 | 100 | rad |
| 轮速 | 10 | rpm |
| 速度 | 1000 | m/s |
| 角速度 | 1000 | rad/s |
| 高度 | 100 | cm |
| 电流 | 100 | A |
| 电压 | 100 | V |

**状态帧（0x100）格式**：

| 字节 | 内容 | 编码 |
| :--- | :--- | :--- |
| 0-1 | 俯仰角 | int16，实际值×1000（rad） |
| 2-3 | 左髋关节角 | int16，实际值×100（rad） |
| 4-5 | 左轮速 | int16，实际值×10（rpm） |
| 6-7 | 故障码 | uint16 |

**速度指令帧（0x200）格式**：

| 字节 | 内容 | 编码 |
| :--- | :--- | :--- |
| 0-1 | 前进速度vx | int16，实际值×1000（m/s） |
| 2-3 | 转向角速度wz | int16，实际值×1000（rad/s） |
| 4-5 | 身体高度 | int16，实际值×100（cm） |
| 6-7 | 保留 | 0 |

**参数配置帧（0x300）格式**：用于在线调整PID/LQR参数，首字节为参数索引，后续字节为参数值，累加和校验。

### B.3 故障码定义

| 故障码 | 含义 | 等级 |
| :--- | :--- | :--- |
| 0x0000 | 无故障 | — |
| 0x0001 | 电池欠压 | 高 |
| 0x0002 | 过流保护触发 | 高 |
| 0x0003 | 电机驱动温度过高 | 中 |
| 0x0004 | IMU通信异常 | 高 |
| 0x0006 | 编码器异常 | 中 |
| 0x0007 | 急停按下 | 高 |
| 0x0008 | 看门狗复位 | 中 |
