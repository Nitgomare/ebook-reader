# 第7章 轮腿复合运动控制

## 7.1 轮式模式速度与转向控制

### 7.1.1 差速驱动模型

在轮式模式下，机器人依靠两个轮毂电机独立驱动，通过差速实现直线前进和原地转向。设左右轮线速度分别为 $v_L$ 和 $v_R$，两轮间距为 $d$（本平台 $d = 280$ mm），则机器人质心处的前进速度 $v$ 和转向角速度 $\omega$ 为：

$$
v = \frac{v_L + v_R}{2}
$$
$$
\omega = \frac{v_R - v_L}{d}
$$

由期望速度指令 $v_{ref}$ 和 $\omega_{ref}$，解算左右轮目标速度：

$$
v_L^{ref} = v_{ref} - \frac{d}{2}\omega_{ref}
$$
$$
v_R^{ref} = v_{ref} + \frac{d}{2}\omega_{ref}
$$

### 7.1.2 轮速控制

每个轮毂电机采用速度环PI控制器，内环为电流环。速度环周期1 kHz，输出为电流参考值。速度反馈由轮毂电机编码器差分获得。

```c
// 轮速控制（1kHz调用）
void wheel_speed_control(void) {
    // 左轮速度环
    float error_L = wheel_L.speed_ref - wheel_L.speed_fb;
    wheel_L.iq_ref = pi_update(&wheel_L.speed_pi, error_L);

    // 右轮速度环
    float error_R = wheel_R.speed_ref - wheel_R.speed_fb;
    wheel_R.iq_ref = pi_update(&wheel_R.speed_pi, error_R);

    // 电流环已在50us中断中执行
}
```

PI参数初始值：$K_p = 0.8,\ K_i = 0.05$，输出限幅 $\pm 3$ A。

### 7.1.3 转向控制

上层导航模块输出 $v_{ref}$ 和 $\omega_{ref}$，底层直接进行差速解算。对于原地旋转（$v=0, \omega\neq 0$），左右轮速度方向相反，需注意轮子打滑和身体扭动。可通过调节身体高度或增加腿部阻尼改善。

## 7.2 腿式步态规划与足端轨迹

### 7.2.1 步态序列设计

腿式模式用于越障、爬坡和复杂地形。采用准静态步态，保证任意时刻至少有一个支撑点，重心投影始终位于支撑多边形内。基本步态序列为：

1. **初始站立**：双腿支撑，轮子锁死。
2. **抬左腿**：左腿轮子离地，右腿支撑。
3. **左腿前伸**：左腿摆动至目标位置。
4. **左腿落地**：恢复双腿支撑。
5. **抬右腿**：右腿轮子离地，左腿支撑。
6. **右腿前伸**：右腿摆动至目标位置。
7. **右腿落地**：恢复双腿支撑，完成一个步态周期。

### 7.2.2 足端轨迹规划

摆动腿的轮心轨迹采用摆线或五次多项式，保证起始和终止时刻速度、加速度为零，减少冲击。

设摆动周期为 $T_s = 0.6$ s，步长 $L_s = 100$ mm，抬腿高度 $H_s = 60$ mm。以髋关节为参考，足端在矢状面内的轨迹为：

$$
x(t) = x_0 + \frac{L_s}{T_s} t - \frac{L_s}{2\pi} \sin\left( \frac{2\pi t}{T_s} \right)
$$
$$
z(t) = z_0 - \frac{H_s}{2} \left[ 1 - \cos\left( \frac{2\pi t}{T_s} \right) \right]
$$

其中 $(x_0, z_0)$ 为摆动开始时刻的足端坐标。通过逆运动学将足端轨迹映射为髋、膝关节角轨迹。

### 7.2.3 步态规划代码实现

```c
// 摆线足端轨迹生成
void swing_trajectory(float t, float T_s, float L_s, float H_s,
                      float x0, float z0, float *x, float *z) {
    float phase = 2.0f * M_PI * t / T_s;
    *x = x0 + L_s * t / T_s - (L_s / (2 * M_PI)) * sinf(phase);
    *z = z0 - (H_s / 2) * (1 - cosf(phase));
}

// 步态循环（简化）
void leg_gait_cycle(void) {
    static float t = 0;
    static int phase = 0; // 0:左腿摆动, 1:右腿摆动
    float T_s = 0.6, L_s = 0.1, H_s = 0.06;

    if (phase == 0) {
        // 左腿摆动
        float x, z;
        swing_trajectory(t, T_s, L_s, H_s, left_swing_x0, left_swing_z0, &x, &z);
        // 逆运动学求解左腿关节角
        if (inverse_kinematics(x, z, &leg_L, &q_hip_L_ref, &q_knee_L_ref) == 0) {
            // 设置关节角度目标
            joint_L_hip.target_angle = q_hip_L_ref;
            joint_L_knee.target_angle = q_knee_L_ref;
        }
        t += 0.001; // 1kHz
        if (t >= T_s) { t = 0; phase = 1; }
    } else {
        // 右腿摆动，类似
        // ...
    }
}
```

## 7.3 轮腿协同控制策略

### 7.3.1 模式切换状态机

机器人工作模式由上层决策，底层执行切换。状态机如下：

```
        ┌──────────────┐
        │   待机模式    │
        └──────┬───────┘
               │ 使能
        ┌──────▼───────┐
        │   轮式模式    │◄──────┐
        └──────┬───────┘       │
               │ 检测障碍/台阶   │
        ┌──────▼───────┐       │
        │   腿式模式    │───────┘
        └──────┬───────┘
               │ 任务完成
        ┌──────▼───────┐
        │   返回轮式    │
        └──────────────┘
```

切换条件：

- 轮式 → 腿式：检测到障碍物高度 $> 30$ mm（超声波或深度相机），且速度 $< 0.5$ m/s。
- 腿式 → 轮式：越障完成，身体姿态恢复水平，轮地接触确认。

### 7.3.2 协同控制

在轮式模式下，腿部关节并非完全锁死，而是采用**阻抗控制**，提供可调阻尼和刚度，适应地面不平并减少振动。关节力矩输出为：

$$
\tau_j = K_p (q_j^{ref} - q_j) + K_d (\dot{q}_j^{ref} - \dot{q}_j)
$$

其中 $K_p$ 和 $K_d$ 为阻抗参数。在平坦路面使用高刚度保持姿态，在颠簸路面降低刚度以吸收冲击。

轮腿协同的典型场景：通过低矮障碍（如减速带）时，轮子持续驱动，同时膝关节主动收缩，提高轮子离地间隙，避免碰撞；通过后恢复伸展。

## 7.4 姿态控制与平衡

### 7.4.1 简化倒立摆模型

双足轮腿机器人的平衡问题可简化为二维倒立摆。设质心高度 $h_c$，俯仰角 $\theta$，轮子提供水平驱动力 $F$ 和力矩 $\tau_w$。线性化动力学（$\theta$ 小角度）：

$$
\ddot{\theta} = \frac{M g h_c}{I_c} \theta - \frac{h_c}{I_c} F
$$

其中 $M$ 为等效质量，$I_c$ 为质心绕轮轴的转动惯量。

### 7.4.2 LQR平衡控制器

选择状态向量 $\mathbf{x} = [x, \dot{x}, \theta, \dot{\theta}]^T$，控制输入 $u = F$。离散化后设计LQR控制器：

$$
u = -\mathbf{K} \mathbf{x}
$$

通过离线求解Riccati方程获得反馈增益 $\mathbf{K}$。在MCU中实现为状态反馈：

```c
// LQR平衡控制（1kHz）
float lqr_balance_control(float x, float x_dot, float theta, float theta_dot) {
    float u = -(K[0]*x + K[1]*x_dot + K[2]*theta + K[3]*theta_dot);
    // 限幅
    if (u > F_MAX) u = F_MAX;
    if (u < -F_MAX) u = -F_MAX;
    return u;
}
```

$K$ 的典型值（本平台参数）为 $[ -0.15, -0.32, 12.8, 2.1 ]$。

### 7.4.3 关节力矩分配

LQR输出的水平力 $F$ 需要转化为轮端驱动力矩 $\tau_w = F \cdot r$。同时，为了抑制身体俯仰，可以通过髋关节施加额外力矩：

$$
\tau_{hip} = K_{hp} \theta + K_{hd} \dot{\theta}
$$

最终轮端力矩和关节力矩共同作用，实现平衡。

## 7.5 越障、爬坡与楼梯通过控制

### 7.5.1 越障流程

以跨过高度 $H_{obs} = 60$ mm 的台阶为例，控制流程如下：

1. **检测与接近**：深度相机/超声波检测到台阶，机器人减速至0.3 m/s，切换至腿式模式。
2. **抬腿**：左腿膝关节弯曲，轮子离地高度 $> H_{obs} + 20$ mm。
3. **前伸**：髋关节前摆，左腿轮子越过台阶上方。
4. **落地**：左腿伸展，轮子接触台阶上表面。
5. **身体上移**：左腿支撑，右腿轮子保持地面，膝关节伸展推高身体，重心前移。
6. **右腿越障**：右腿执行同样动作。
7. **恢复**：双腿轮子均在台阶上，切换回轮式模式继续行驶。

### 7.5.2 爬坡控制

在坡面（坡度 $\alpha \le 15^\circ$）行驶时，轮式模式可直接应对，但需调整身体姿态保持水平。坡面检测通过IMU俯仰角反馈。控制策略：

- 将IMU测量的身体俯仰角与期望俯仰角（$0^\circ$）的误差输入平衡控制器。
- 增加轮端输出力矩以克服重力沿坡面的分量：$F_{slope} = M g \sin\alpha$。
- 必要时启动腿式模式，通过关节调整保持轮子充分接地。

### 7.5.3 楼梯通过

楼梯攀爬采用准静态步态，每次抬升一级台阶。台阶高度 $h_{step} = 150$ mm 时，需充分发挥髋、膝关节运动范围。步态周期约2 s，抬腿高度 $> h_{step} + 30$ mm。身体重心通过调整另一条支撑腿的膝关节保持稳定。楼梯攀爬对地面摩擦和关节力矩要求较高，建议仅在必要时使用。

## 7.6 控制算法代码实现与调参

### 7.6.1 主控制循环

底层1 kHz控制中断中按顺序执行：

```c
void TIM6_DAC_IRQHandler(void) {
    HAL_TIM_IRQHandler(&htim6);
    // 1. 传感器读取
    imu_read(accel, gyro);
    read_joint_encoders();
    read_wheel_encoders();

    // 2. 姿态估计（互补滤波）
    attitude_update(accel, gyro, &attitude);

    // 3. 根据模式执行控制
    switch (mode) {
        case MODE_WHEEL:
            wheel_speed_control();
            balance_control();   // LQR输出叠加到轮端
            break;
        case MODE_LEG:
            leg_gait_cycle();
            joint_position_control();
            break;
        case MODE_STANDBY:
            // 关节力矩置零或保持
            break;
    }

    // 4. 发送状态帧
    send_status_frame();
    // 5. 喂狗
    HAL_IWDG_Refresh(&hiwdg);
}
```

### 7.6.2 姿态估计（互补滤波）

```c
void attitude_update(float *accel, float *gyro, attitude_t *att) {
    float dt = 0.001f;
    // 加速度计计算俯仰角
    float acc_pitch = atan2f(-accel[0], sqrtf(accel[1]*accel[1] + accel[2]*accel[2]));
    // 陀螺仪积分
    att->pitch += gyro[1] * dt; // 绕Y轴角速度
    // 互补滤波
    const float alpha = 0.98f;
    att->pitch = alpha * att->pitch + (1 - alpha) * acc_pitch;
}
```

### 7.6.3 调参方法

| 参数 | 初始值 | 调参方向 |
| :--- | :--- | :--- |
| 轮速PI | $K_p=0.8, K_i=0.05$ | 增大$K_p$响应快但可能振荡，$K_i$消除静差 |
| LQR增益 | 按模型计算 | 保持稳定裕度，可手动微调$K[2]$增大抗扰 |
| 互补滤波系数 | $\alpha=0.98$ | 越大越信任陀螺仪，越小越信任加速度计 |
| 关节位置PI | $K_p=3.0, K_i=0.1$ | 增大$K_p$提高跟踪精度，过大引起抖动 |
| 阻抗刚度$K_p$ | 5 N·m/rad | 平坦路面增大，颠簸路面减小 |

调参步骤：先调电流环（50 μs），再调速度环（1 ms），最后调平衡环（1 ms）。在悬空状态下调试，再落地。

## 7.7 实战：多模式切换测试与参数整定

### 7.7.1 任务目标

在实物平台上实现轮式模式、腿式模式及模式切换，验证越障和平衡控制。

### 7.7.2 测试步骤

1. **安全准备**：机器人置于测试场地，周围设置软垫，急停开关就绪。
2. **轮式模式测试**：上电使能，发送前进/转向指令，观察速度跟踪和转向平滑性。
3. **平衡测试**：在静止状态轻微推动机器人，观察是否快速恢复站立。
4. **腿式模式测试**：发送越障指令，观察步态执行和足端轨迹。
5. **越障测试**：放置60 mm台阶，执行越障流程，记录成功率和时间。
6. **模式切换测试**：在行驶中触发模式切换，检查切换过程和稳定性。

### 7.7.3 常见问题与排查

| 问题 | 可能原因 | 排查方法 |
| :--- | :--- | :--- |
| 轮式模式速度振荡 | 速度环$K_p$过大、编码器噪声 | 减小$K_p$，滤波编码器 |
| 平衡失效，向后倒 | LQR增益不当、质心估计错误 | 重新标定质心，调整增益 |
| 腿式步态抬腿高度不够 | 逆运动学解算错误、关节限位 | 检查关节角范围，调整轨迹参数 |
| 模式切换时摔倒 | 切换条件不满足、执行过快 | 降低切换速度，增加过渡 |
| 越障时轮子打滑 | 地面摩擦不足、力矩过大 | 降低轮端力矩，增加轮胎花纹 |

完成本章实战后，读者应能掌握轮腿复合运动控制的核心算法和调试方法，为后续章节的导航与任务系统奠定运动基础。
