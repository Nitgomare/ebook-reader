>

>
> **内容制作：辛庆浩**
>
> 目标：建立脚本、录屏、剪辑、字幕、封面和导出的标准化可复现流程，产出课题组科研技能教学视频，视频建议时长10‑15分钟，分辨率1080P。
>
> 工具环境说明：本教程全部使用Windows平台免费工具：**EV录屏（录屏采集） + Clipchamp（剪辑、音频处理、字幕、封面制作）**，无需安装付费软件，普通Windows电脑即可完整复现整套流程。

## 一、适用场景
本套流程面向课题组内部科研技能教学，适合以下场景：
1. 科研技能教学：文献检索、Python实操、软件操作、绘图教学等录播教学视频
2. 组会汇报预录视频：不方便现场汇报时录制汇报录像
3. 实验操作演示：软件操作、仿真操作录屏演示
4. 对外分享素材：课程分享、线上讲座备份素材

> 时长参考：本项目统一建议成品视频控制在 **10‑15分钟**；超过18分钟建议拆分为上下两集。

## 二、前期准备
### 2.1 工具清单
|环节|工具|用途|
|---|---|---|
|脚本撰写|VS Code / Typora / Word|编写视频脚本、分镜|
|录屏|EV录屏（PC免费版）|电脑屏幕录制，采集操作画面与麦克风声音，无强制水印（选择免费模式）|
|剪辑&字幕&音频&封面|Clipchamp（Windows系统自带）|视频拼接裁剪、音频降噪、音量调节、自动字幕生成校对、封面图制作、视频导出|

> 硬件要求：优先使用带麦克风的耳机，尽量避免笔记本自带麦克风，减少环境噪音、电流杂音。
> 重要提示：Clipchamp为Windows自带应用，可直接在开始菜单搜索`Clipchamp`打开，不需要额外下载安装。

### 2.2 EV录屏关键参数配置
打开EV录屏，在主界面完成如下设置：
1. **录制区域**：选择「全屏录制」，保证1920×1080完整屏幕采集
2. **音频设置**：勾选「系统声音」+「麦克风声音」；麦克风选择自己实际使用的耳机麦克风设备
3. **视频参数**
    - 帧率：`30fps`
    - 输出分辨率：`1920×1080(1080P)`
    - 视频格式：`MP4`
4. **保存设置**：自定义素材保存文件夹，建议路径`原始录屏素材/`，方便后续查找源文件
5. **预测试操作**：点击录制，录制30秒测试片段，播放回放确认两点：
   - 屏幕画面完整，没有裁切
   - 麦克风人声、系统声音录制正常，无杂音爆音

> 实操建议：不要一次性录完整段视频，按照脚本分段录制，出错就停止，重录该片段，后期在Clipchamp拼接。
> 素材保存：EV录屏输出的原始mp4源文件统一存放在`原始录屏素材/`文件夹，**不要删除原始素材**，方便后续二次修改剪辑。

## 三、脚本撰写
> 核心原则：**先写脚本再录屏，禁止边思考边录制**，极大减少后期剪辑工作量，保障视频逻辑通顺、操作可以复现。

### 3.1 语速估算
正常科研讲解语速约 **220‑250字/分钟**。
示例：12分钟视频，脚本总字数预估：2400‑3000字。

### 3.2 分镜脚本模板
|镜号|时长|画面内容|台词脚本|备注|
|---|---|---|---|---|
|01|00:00‑00:40|片头封面画面|大家好，本期视频我们学习XXX技能……|片头，介绍本视频学习目标、适用人群|
|02|00:40‑03:00|软件界面录屏|接下来我们完成第一步操作……|实操演示部分|
|03|……|……|……|……|
|END|末尾30s|总结画面|以上就是本期全部内容，总结要点……|收尾总结|

### 3.3 脚本内容要点
1. 开篇：说明本视频适用人群、学习目标
2. 主体：分步演示操作，每一步讲清楚“做什么+为什么这么做”
3. 中间插入注意点、易错提醒
4. 结尾：内容总结，列出常见坑点，提示配套MD文档可以查阅详细文字资料

> 课题组案例建议：脚本示例主题可以选用《Python风电数据分析快速上手》作为示范案例，贴合本课题组风电、能源方向。

## 四、录屏采集流程
1. 录制前准备：关闭电脑弹窗通知，清理桌面无关文件，将要演示的软件窗口摆放整齐。
2. EV录屏核对全部参数：录制区域、音频来源、帧率分辨率，确认和第二节配置一致。
3. 点击「开始录制」快捷键（默认快捷键`Ctrl+F1`开始，`Ctrl+F2`停止录制）。
4. 按照脚本分段录制，一段脚本完成一个片段；一旦口误、操作失误，直接按停止快捷键，重新录制该片段。
5. 每录完一段，打开输出文件夹确认MP4文件正常生成，没有损坏。

> 小技巧：录屏过程中不要临时更改操作思路，严格依照脚本演示，保证视频内操作流程具备可复现性。

## 五、视频剪辑操作Clipchamp
1. Windows开始菜单搜索打开`Clipchamp`，点击「创建新视频」。
2. 设置项目基础属性：项目分辨率设置为 **1080P，30fps**。
3. 导入素材：把EV录屏输出的全部原始录屏片段导入媒体库，按照脚本时间顺序拖拽到时间轴轨道上。

### 5.1 粗剪
1. 使用分割工具，切割时间轴视频；删除口误、长时间停顿、操作失误片段。
2. 调整片段顺序，对齐脚本流程。

### 5.2 音频处理
1. 选中时间轴上视频片段，点击右上角「音频」选项。
2. **音频降噪**：开启「背景噪音消除」，消除环境杂音。
3. **音量标准化**：使用“标准化音量”功能，统一全部片段人声大小，避免忽大忽小。

> 科研教学视频不建议使用音量过大的背景音乐；如需添加背景音乐，背景音乐音量调至远低于人声，也可以不添加背景音乐。
4. 重点操作位置，可使用「标注」添加方框高亮，框选鼠标操作区域，方便观看者跟上操作步骤。

## 六、字幕制作流程
1. 在左侧菜单栏选择「文本」→「自动字幕」，选择语言为中文，点击“生成自动字幕”，AI自动识别视频人声生成字幕初稿。
2. ⚠️**强制要求人工逐句校对字幕**：科研视频大量专业术语（风电、Python、MkDocs、文献计量等），AI自动识别经常出错，不可直接使用自动生成结果。
3. 字幕样式统一设置
    - 字体：微软雅黑
    - 字号：40‑44
    - 添加黑色描边，描边粗细2‑3px，浅色画面下保证文字可读
    - 摆放位置：画面底部，不能遮挡软件操作界面。
4. 长句拆分：不要单行大段文字，长句子拆分为两行展示。

> 交付要求：最终视频内嵌字幕；如需备份，可在Clipchamp中将字幕导出SRT字幕文件，放到素材文件夹归档。

## 七、视频封面制作
### 封面必备要素
1. 大标题：专题名称，如「科研教学视频制作全流程」
2. 小字标注：课题组科研技能教学
3. 配图：软件界面截图，风格简洁，拒绝花哨装饰。
4. 尺寸：1920×1080，和视频分辨率保持一致。

### Clipchamp制作封面实操：
1. 在时间轴最开头添加一个空白色块，时长设置3‑4秒，作为片头封面。
2. 选中空白色块，添加文本，输入标题、副标题。
3. 可以导入软件截图作为背景图层，排版完成。
4. 也可以单独把封面画面导出为PNG图片，保存到`封面素材/`文件夹归档。

## 八、视频导出与文件归档

> 注意：Clipchamp免费版本最高支持1080P输出，不要选择4K；等待渲染导出，不要关闭软件。
4. 文件命名严格执行：`辛庆浩-科研教学视频制作.mp4`

## 九、完整实例演示（基于课题组风电案例）
> 模拟案例场景：录制一段12分钟教学样例，主题演示“如何使用EV录屏+Clipchamp制作一份Python风电数据分析教学视频”，贴合课题组研究方向。

1. 脚本总字数设置约2600字，预估11‑13分钟。
2. 分镜规划：片头封面（40s）→ EV录屏参数配置教学（3min）→脚本撰写演示（3min）→Clipchamp剪辑、降噪、字幕实操（4min）→总结收尾（1min）。
3. 录屏：电脑打开EV录屏、Clipchamp软件窗口，分段录制各个片段。
4. 剪辑：导入全部片段，粗剪去掉卡顿口误片段，开启背景噪音消除，标准化音量。
5. 字幕：生成自动字幕，人工校对，修正EV录屏、Clipchamp、风电数据分析等专有名词识别错误。
6. 封面：在Clipchamp内制作片头封面，标题：科研教学视频制作全流程｜课题组技能培训。
7. Clipchamp导出1080P MP4，按命名规范保存，归档全部原始素材。

## 十、常见问题与解决方案
1. **EV录屏录制出来没有声音**
    > 排查：EV录屏音频设置，麦克风设备是否选对；Windows系统麦克风权限是否开启；录制前做30秒测试片段确认收音。

2. **Clipchamp导出视频渲染失败、卡住**
    > 解决方案：关闭电脑其他占用内存软件；视频片段过多时，可以分段处理；确认项目设置是1080P，不要设置高于1080P。

3. **自动字幕大量识别错误专业名词**
    > 必须人工逐句校对；风电、软件名称、专业术语不能依赖AI识别。

4. **EV录屏画面被裁切，录不全屏幕**
    > EV录屏录制区域选择“全屏录制”，不要自定义框选小区域；录制前回看测试片段确认画面完整。

5. **麦克风杂音、电流音很重**
    > 使用耳机麦克风，尽量不用笔记本自带麦；录制环境远离噪音；后期在Clipchamp打开背景噪音消除。

6. **录屏片段丢失**
    > EV录屏确认保存路径，每录完一小段就去文件夹确认MP4文件生成，不要一次性录制超长片段。

7. **成品视频时长超过15分钟**
    > 精简脚本，删减冗余演示内容；如果内容无法删减，则拆分为视频上、下两部分。

8. **Clipchamp找不到自动字幕功能**
    > 在左侧菜单栏找到【文本】标签，下拉找到自动字幕；如果版本差异看不到，更新Windows应用商店里的Clipchamp。
