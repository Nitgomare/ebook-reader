# 科研工具与实践

面向研究生和科研新手的实用工作流，覆盖文献检索、Zotero 管理、格式转换、知识库搭建、Python 数据处理和实验复现。

## 学习模块

1. **文献检索与管理**：建立检索式、筛选论文，并使用 Zotero 管理文献。
2. **格式转换与术语**：处理 PDF、Markdown、HTML 与中英文术语。
3. **知识库搭建**：从本地文档到 GitHub 和 Cloudflare Pages 的完整发布流程。
4. **编程与实验复现**：使用 Python、NumPy 和可复现项目结构完成科研实践。

建议先从左侧目录选择当前最需要解决的问题，再按专题顺序继续学习。
