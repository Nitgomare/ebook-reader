## 推荐使用顺序

1. 用课件快速建立本章结构，记下三个关键词。
2. 阅读正文，补齐定义、公式和边界条件。
3. 打开 `tiny_ml` 对应实现，沿着数据形状、目标函数、参数更新和停止条件阅读。
4. 最后看视频中仍不清楚的分 P，并用自己的话写一段解释。
