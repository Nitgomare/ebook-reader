# 第8章 学习资料

> 主编：何志鹏、龙东平、马文悦、邓越平  
> 湖南科技大学机电工程学院 · 2026年10月

本章汇总的资源分为六个板块：官方学习平台与认证体系为学习者提供标准化的能力检验路径；系统化的视频课程覆盖从软件操作到复杂装配的全流程；机器人专项资源直接对应前七章涉及的机械臂、手爪与移动平台建模；开源项目与模型库将几何建模与真实的机器人研发链条连接起来；从几何到控制的衔接资源帮助学习者理解“模型建成之后会发生什么”；竞赛与设计案例则展示了SolidWorks建模在机器人工程实践中的实际应用场景。

## 8.1 官方学习平台与认证体系

达索系统为SolidWorks提供了两条并行的学习路径：**MySolidWorks在线学习平台**和**官方认证考试体系**。

MySolidWorks是SolidWorks官方的在线学习入口，提供结构化的Learning Paths、分模块的Lessons以及配套的练习和测验。**自2026年7月11日R2026x FD03版本发布起，MySolidWorks上的全部Lessons和Learning Paths已对所有学习者免费开放**，涵盖CSWA/CSWP备考、钣金设计、装配体设计、仿真等多个方向。学生只需注册一个MySolidWorks账户，即可访问数百个专家讲授的独立模块和结构化课程，包括为官方认证考试准备的完整学习路径。

- **MySolidWorks学习平台**：<https://my.solidworks.com/>
- **MySolidWorks课程目录（中文界面）** ：<https://my.solidworks.com/training/catalog/list/1?q=exam&category=f%2Fdb_record_sublevel%2FStandard&sort=dateasc&lang=cn>

在认证方面，SolidWorks提供**CSWA（Certified SOLIDWORKS Associate，助理级）** 和**CSWP（Certified SOLIDWORKS Professional，专业级）** 两个核心认证。CSWA考试覆盖草图绘制、基本特征、质量属性、装配体和工程图等基础内容；CSWP则进一步考察零件建模与配置修改、装配体建模以及更复杂的特征操作。对于完成了本教材前七章建模练习的学生，CSWA是一个合理的能力检验节点；如果后续需要从事机械设计或机器人结构设计相关工作，CSWP的零件建模与装配体部分与本教材的训练内容高度重合。考试报名可通过SolidWorks官方授权的培训认证中心进行，例如微辰三维作为大中华区官方授权中心，提供CSWA和CSWP的报名通道。

- **SolidWorks认证官方考试指南与样题**：<https://www.solidworks.com/cswa>
- **CSWA/CSWP备考Learning Path（MySolidWorks）** ：<https://my.solidworks.com/training/catalog/list/1?q=exam>

此外，SolidWorks官方帮助文档中的**Learn选项卡**内置了Step-by-Step Tutorials，与软件安装同步提供，适合在操作过程中随时查阅具体命令的用法。SolidWorks官方YouTube频道和B站官方账号也会不定期发布功能演示和建模技巧视频，其中包含扫地机器人、机械臂等机器人相关模型的Visualize渲染和建模演示。

## 8.2 系统化视频课程：从软件操作到机械臂建模

对于需要系统、完整地跟随视频学习的读者，以下课程资源按照“基础操作—机械臂专项—综合进阶”的顺序排列。

**阿奇设计分享：《阿奇讲SOLIDWORKS机械臂》** 是B站上与本教材第7章内容衔接最紧密的课程之一。该课程共29课时，系统讲解机械臂设计与SolidWorks应用，涵盖草图绘制、零件转换、装配体设计、运动优化等全流程，累计播放量超过166万次。课程的特点是围绕“机械臂”这一具体对象展开，学生在学习过程中始终有一个明确的建模目标，而不是孤立地练习软件命令。该UP主还发布过SOLIDWORKS练习题集和直线模组原理讲解，可以作为机械臂建模之外的补充练习。

- **阿奇讲SOLIDWORKS机械臂（B站）** ：在B站搜索“阿奇讲SOLIDWORKS机械臂”即可找到课程合集；UP主主页可通过B站用户“阿奇设计分享”访问。

如果需要从零基础开始、覆盖面更广的系统教程，**B站上的长系列SolidWorks入门课程**可以作为备选。例如“全368集SolidWorks教程”和“全500集SolidWorks零基础全套教程”均覆盖草图、零件、装配体、工程图以及有限元分析入门，适合在建模过程中遇到具体功能不熟悉时按需检索对应章节。这类长系列课程的优势在于索引详细，但内容体量较大，建议不要从头到尾线性观看，而是以本教材的章节任务为驱动，遇到不熟悉的命令时跳转到对应片段。

- **B站SolidWorks入门长系列（示例）** ：在B站搜索“SolidWorks 零基础 全套”即可获得多个高播放量的系统课程列表。

## 8.3 机器人建模专项资源

本教材第5—7章分别涉及智能小车、五爪夹持手爪和智能机械臂。以下资源直接对应这三类建模对象。

**（1）SO-101机械臂的开源模型与文档。** SO-101由TheRobotStudio与Hugging Face联合开源，采用Apache-2.0协议，包含SO-100和SO-101两款机械臂的全部3D打印模型（STL/STEP格式）、装配文档、采购清单以及仿真文件。对于第7章的建模学习而言，这个仓库的价值在于：你可以将自己的建模结果与开源设计进行**逐零件对照**，检查连杆长度、关节轴线方向和配合面的几何定义是否一致。项目仓库中的零件清单也有助于理解每个几何特征在实际装配中的功能。

- **SO-ARM100/101 GitHub仓库**：<https://github.com/TheRobotStudio/SO-ARM100>
- **GrabCAD上的SO-101模型页面**（可用于参考装配结构）：<https://account.grabcad.com/>

**（2）夹爪与传动机构的装配参考。** 第6章的五爪夹持机构涉及齿轮同步和连杆配合。一份名为“移动机器人SolidWorks组件夹爪装配”的课件详细演示了夹爪齿轮安装板、轴承和同轴心配合的添加顺序，可以作为第6章装配练习的补充参考。此外，关于SolidWorks中**齿轮配合**的操作，核心是在装配体环境中使用“机械配合→齿轮”，选择两个齿轮的分度圆或圆柱面来建立传动比关系，而不是依赖齿面的物理接触。

- **夹爪装配课件（PPT）** ：<https://max.book118.com/（搜索“移动机器人SolidWorks组件夹爪装配”>）
- **四自由度码垛机械臂建模与装配指南（附源文件）** ：<https://blog.csdn.net/（搜索标题即可>；该文涵盖齿轮配合与齿侧间隙处理）

**（3）机器人建模的系统教材与案例集。** 如果需要超越单个对象、从系统层面理解机器人建模，以下两本书可以作为延伸阅读。《SolidWorks机械设计与工业机器人方案设计案例详解》的进阶篇涵盖工业机器人末端执行器、焊接工装夹具和工作站的具体建模案例。《玩转机器人：基于SolidWorks的设计实例（移动视频版）》则以四轮循迹小车、两轮小车、双足机器人和六旋翼飞行机器人为对象，覆盖了移动机器人几何建模的主要类型，与本教材第5章的智能小车建模形成互补。

## 8.4 从几何模型到机器人仿真：URDF导出与ROS衔接

本教材的重点是几何建模，但一个在SolidWorks中“看起来正确”的装配体，还需要经过**运动学定义和坐标系配置**，才能成为机器人控制算法可以使用的模型。将SolidWorks装配体导出为**URDF（Unified Robot Description Format）** ，是连接几何设计与ROS/ROS2仿真的标准路径。

SolidWorks社区提供了 **“SolidWorks to URDF Exporter”** 插件。使用流程大致如下：在装配体中为每个连杆（link）定义参考坐标系，为每个关节（joint）指定类型（旋转、平移、固定等）和旋转/平移轴，然后通过插件导出URDF文件以及配套的mesh文件。导出的URDF包可以直接在ROS的RViz中可视化，或导入Gazebo进行物理仿真。ROS Wiki上提供了该插件的官方安装说明和分步教程，涵盖从坐标系定义到关节配置的完整流程。对于本教材第7章的SO101机械臂，如果你在装配体中已经正确定义了各关节的旋转轴线和连杆坐标系，导出URDF的过程实际上是对建模阶段关节轴线几何精度的一次严格检验——轴线方向或原点位置的微小偏差，在RViz中会被直接暴露出来。

- **ROS Wiki：sw_urdf_exporter**：<http://wiki.ros.org/sw_urdf_exporter>
- **URDF Exporter教程**：<http://wiki.ros.org/sw_urdf_exporter/Tutorials>
- **SolidWorks导出URDF并导入ROS的详细教程（CSDN）** ：<https://blog.csdn.net/（搜索“solidworks导出urdf> 导入ros 详细教程”）

此外，湖南科技大学智能机器人微专业建设了基于**ROS2-Gazebo**的虚拟仿真平台，支持24小时预约使用，学生可以在该平台上将SolidWorks导出的URDF模型放入工业场景中进行编程与调试。这一资源与本教材的衔接关系是：几何建模提供URDF的mesh和关节定义，Gazebo则在此基础上验证运动学与动力学行为。

## 8.5 竞赛与设计案例：SolidWorks在机器人工程中的真实用法

对于希望在课程之外检验建模能力或寻找项目灵感的学生，机器人竞赛是一个直接的出口。SolidWorks在多个大学生机器人竞赛中承担着结构建模与工程图输出的核心角色。

**中国机器人大赛**的设计组明确要求参赛队使用SolidWorks等主流CAD软件完成地面可移动机器人的三维建模与工程图绘制，并提交完整的设计图纸和设计说明书。RoboMaster参赛队的机械组则使用SolidWorks进行机器人结构建模与优化设计，并负责后期的实际装配。一个开源的**轮式格斗机器人**项目（基于STM32+树莓派，3.5 kg级）在其GitHub仓库中公开了完整的SolidWorks 2023装配体源文件，可以作为从几何建模到实物制造全流程的参考案例。

- **轮式格斗机器人SolidWorks源文件（GitHub）** ：<https://github.com/waodfi/Combat-Robot>
- **中国机器人大赛设计组（陕西理工大学承办信息）** ：<https://jxxy.snut.edu.cn/>

如果在竞赛或项目中涉及**机械臂夹爪的同步传动**，除了第6章的连杆方案外，齿轮联动夹爪也是一个常见的替代构型。这类结构通过多组直齿圆柱齿轮实现两指的同步开合，从几何上规避了单轴驱动的不同步问题，适合在小负载精密取放场景中使用。尝试用SolidWorks完成一个齿轮联动夹爪的建模与装配，可以作为第6章手爪建模的一个进阶变体练习。

## 8.6 学习路径建议

最后，给出一个按优先级排列的课外学习路径，供不同基础和目标的读者参考。

**如果目标是巩固本教材的建模技能**：优先完成MySolidWorks上CSWA备考的Learning Path（免费），配合“阿奇讲SOLIDWORKS机械臂”课程中的对应章节，将教材中的手爪和机械臂模型独立复现一遍。

**如果目标是参加机器人竞赛或进入实验室项目**：在掌握基本建模后，选择一个开源机器人项目的SolidWorks源文件进行“逆向学习”——不查看原作者的步骤，自己从零件开始重建，再与原文件逐特征对照，定位自己在特征顺序、配合定义或设计意图表达上的差异。轮式格斗机器人开源项目和SO-101仓库都适合作为逆向学习的对象。

**如果目标是向机器人控制或仿真方向延伸**：以本教材第7章的SO101装配体为基础，完成URDF导出并在RViz或Gazebo中验证关节运动。这一步会遇到的问题——坐标系方向反了、关节轴线偏移、mesh路径错误——恰好是几何建模与控制系统之间“接口约定”的具体体现。解决了这些问题，几何模型才真正成为机器人系统的一个可用组成部分。
