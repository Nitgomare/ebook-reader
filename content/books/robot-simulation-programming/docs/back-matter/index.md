机器人技术和人工智能正处于当前时代发展的前沿，整个社会对于机器人技术的重视度之高前所未有。而这本书的出现很好地满足了人们对于机器人技术的需求。书中详尽叙述了机器人相关的仿真软件以及研究技术，初学者可以从中学习到机器人的基本技术和仿真应用方法，而相关领域的高级工程师可以通过这本书接触到当前的机器人前沿技术。可以预见，本书的出现会在这个领域掀起新的研究热潮。

——于振中 哈工大机器人集团（HRG）高级副总裁

《机器人仿真与编程技术》是一部内容丰富且极具实用性的专著。书中不仅介绍了MATLAB机器人工具箱及其他3个仿真软件，还详细介绍了机器人操作系统（ROS），同时还结合作者已发表的论文进一步阐述，并附上相应的程序代码，增强了本书的实用性和可读性。

——李庆民 山东创泽信息技术股份有限公司董事长

——李瑞峰 哈尔滨工业大学机器人研究所常务副所长

——刘小峰 江苏省特种机器人重点实验室副主任
