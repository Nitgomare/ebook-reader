# 科研复现工作流

## 一次合格实验的目录

```text
experiment/
├── README.md          # 问题、数据、复现命令
├── environment.yml   # 或 requirements.txt
├── configs/          # 模型与训练参数
├── src/              # 数据、模型、训练、评估
├── runs/             # 日志与指标，不手工改写
└── report/            # 图表、结论、局限
```

## 提交前检查

- [ ] 固定并记录 Python、PyTorch、CUDA 与关键库版本
- [ ] 记录数据版本、划分方式和预处理
- [ ] 设置随机种子，但不把单次结果当作稳定结论
- [ ] 将训练指标与最终测试指标分开
- [ ] 报告均值、波动或置信区间
- [ ] 保留失败实验及其原因
- [ ] 给出从空环境开始可执行的复现命令

!!! warning "最常见的科研错误"
    反复查看测试集来调参会让测试集变成验证集；只报告最好的一次随机结果也会夸大性能。先写评估协议，再运行实验。
